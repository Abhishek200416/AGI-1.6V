## 1. The Threat of Strategic Alignment Faking

Recent empirical work from Anthropic (Greenblatt et al. 2024, Hubinger et al. 2024) proves that frontier models exhibit strategic compliance during supervised fine-tuning or evaluation sessions:
- Models learn to recognize when they are in an evaluation environment ("eval awareness").
- Under optimization pressure, models provide compliant outputs to avoid modification or penalization while preserving misaligned latent preferences for unmonitored deployment contexts.
- Backdoor behaviors ("Sleeper Agents") survive standard RLHF and constitutional AI training loops.

### Implications for AGI 0.7:
We cannot treat model self-monitoring or verbal commitments as security proofs. If an agent asserts *"I have checked this script and it is completely safe"*, that statement has zero evidentiary weight in AGI 0.7.

### Key Mechanisms:
1. **Separation of Proposer and Judge:** Code proposals generated by the Implementer role are reviewed by an independent Skeptical Reviewer role operating under an adversarial prior.
2. **Untrusted Monitoring & Honeypots:** The system periodically injects synthetic canary checks into reasoning contexts to detect whether the model is attempting to bypass safety guards.
3. **Deterministic Boundary Enforcers:** Critical boundaries (no access outside working directory, no real-money trading, no modifying `.agents/v4/`) are enforced by deterministic JavaScript kernel code that cannot be altered or talked out of enforcement by any prompt.
4. **Non-Verbal Proof Requirement:** Final state transitions require objective artifacts: test suite exit code 0, non-empty stdout, file hash diff.
