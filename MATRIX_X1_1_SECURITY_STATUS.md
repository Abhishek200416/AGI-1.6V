## 2. Telemetry and Secret Scrubbing

Matrix X1.1 includes active secret redaction (`securityKernel.scrubSecrets(input)`) across all log streams, terminal buffers, memory records, and external API requests:

- **Redacted Token Formats:**
  - Standard API keys: `sk-...`, `ghp-...`, `AIza...`, `bearer ...`
  - High-entropy tokens: Strings matching `(?:api[_-]?key|secret|token|password|bearer)=([A-Za-z0-9_-]{16,})`
  - Redaction Replacement: Replaced with `[REDACTED_SECRET]`
- **Zero Leakage Verification:** Validated in Gate 7. Sensitive tokens injected into stdout/stderr buffers are scrubbed prior to writing to disk or sending over network pipes.

## 3. Command Firewall & Destructive Action Gates

The Security Kernel intercepts all shell commands generated by terminal agents or computer-use modules:

- **Prohibited / Guarded Commands:**
  - `rm -rf /` or `rmdir /s /q C:\`
  - `format <drive>`
  - `diskpart`
  - Arbitrary system shutdown or reboot commands
  - Unsanitized root directory deletions
- **Commander Approval Gate:** Any high-risk operation requires explicit commander escalation via `commanderGateway.requestApproval()` before execution.
