# Directive 0 (Sole Foundation Model Policy)

Mandate enforcing that Google Gemini 3.8 Flash High (`gemini-3.8-flash-high`) serves as the sole permitted foundation model for [[AGI 1.6 OMEGA NEXUS]].

## Invariants
- Zero silent fallback to low/medium effort or non-Gemini models.
- Invoked via authenticated Antigravity CLI binary (`agy.exe --dangerously-skip-permissions`).
- Automatic proxy scrubbing (`HTTP_PROXY`, `HTTPS_PROXY` stripped).

Connected to: [[AGI 1.6 OMEGA NEXUS]], [[Central Budget & Effort Controller]], [[DynTaskMAS DAG Scheduler (500 Workers)]]
